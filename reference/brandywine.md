# Brandywine Tide Height Data

High/Low Tide Predictions from
<https://tidesandcurrents.noaa.gov/tide_predictions.html>.

## Usage

``` r
brandywine
```

## Format

A tbl data frame:

- Station:

  The station name (chr).

- DateTime:

  The date time (time).

- MLLW:

  The tide height in m (dbl).
